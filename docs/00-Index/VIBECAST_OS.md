# VibeCast — GCS wing (not a second house)

**Parent studio:** **[[GCS_CITADEL|GCS — Gaming Content Studio]]**  
**Brand:** **TWE** (The WoW Explorer)  
**This wing:** your real play+talk nights → daily + podcast drafts  

VibeCast is a **cool name for a room inside the citadel**, not a rival OS.  
Sibling wing: **Factory** (Saturday zone carousels for TWE/TDE/TFE).  
Shared exit: **Armory** (packages · your publish go).

**One job for you:** play and talk when it feels good.  
**One job for agents:** harvest into Returner Daily + essay drafts under GCS·TWE.  
**Never:** edit on the couch · publish · open five vault notes · open factory folders on play night.

**Play door:** [[KYLE_OS]] · **Even simpler:** [[SIMPLE_START]]

## What “vibe-cast” means here

| Word | Meaning for you | Meaning for agents |
|------|-----------------|--------------------|
| **Vibe-cast** | Play + optional talk · soft stream energy · stop when fun ends | Long take → peaks → clips + stills |
| **Vibe-podcast** | Same night **or** clean flight-path talk · listen-first later | Audio essay / show-notes / Mac essay drop |
| **Returner Daily** | You don’t assemble it | Carousel 1 video + 1 Memento still |
| **EP series** | Only when you choose Talk clean | Clean chapters · registry EP01–07 |

You are **not** running three careers. One vibe night can feed **all** of them.

```
You (vibe night)
  ├─ play only          → Memento stills + B-roll paths
  ├─ talk muddy         → vibe-cast primary fuel
  └─ talk clean         → vibe-podcast / EP fuel
         │
         ▼ agents
  Returner Daily (carousel)  ·  clip peaks  ·  essay/podcast draft  ·  package NOT_ARMED
         │
         ▼ you
  publish go only
```
