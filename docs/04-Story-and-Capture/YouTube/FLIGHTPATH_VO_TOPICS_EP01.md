## Topic spine (glance while flying)

Work **top → bottom**. Skip any that don’t feel true tonight.  
~1–2 minutes each is plenty.

### Block A — What Wrath still means
- [ ] Icecrown / Arthas as a story that *felt* like an ending  
- [ ] Muscle memory: old social glue · Northrend cold · era that lived in your hands  
- [ ] Account ghosts OK (old mains / old realms) — **no level lecture**  
- [ ] Optional: **Crimsonpain** as the DK fantasy anchor (not a gear flex)

### Block B — What “veteran” is *not*
- [ ] Not knowing every modern system  
- [ ] Not winning “best expansion” arguments  
- [ ] Permission to be confused and still belong  
- [ ] Years away — **don’t invent a last-login year** unless you’ve stated one

### Block C — Why return *now*
- [ ] Friend along the way (**Mac**) — gratitude one-liner, **not** an interview  
- [ ] Midnight / modern era = **door we walked through**, not a patch sermon  
- [ ] Success = fun nights + archive — not “caught up”

### Positive friction (use if something annoys you mid-flight)
- [ ] Name it: “friction for a returner…”  
- [ ] Show fight: what you’re doing anyway (flying, one system later)  
- [ ] Invite: “got this too? workaround?”  
- [ ] Soft letter: one sentence for the devs — feedback, not hate  
- [ ] Curiosity: “next login I’ll try…”
