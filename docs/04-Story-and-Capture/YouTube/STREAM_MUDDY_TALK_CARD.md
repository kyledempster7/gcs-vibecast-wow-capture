## Rules (keep tiny)

1. Play the game. Talk when you feel it.  
2. **No wiki.** No patch-tab rabbit holes.  
3. Mac silent if she’s on — never interview her.  
4. Stop when fun ends. Long file is OK.  
5. Agents will **not** auto-label this as EP01 Recorded unless you say so.
