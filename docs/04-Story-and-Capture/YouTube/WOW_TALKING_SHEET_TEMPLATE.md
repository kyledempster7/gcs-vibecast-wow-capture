# WoW Talking Sheet — Template

**Use:** duplicate this note for one video. Write fragments, not a script. Keep the line that sounds most like you, then build the smallest useful shape around it.

**Creative rails:** [[CREATIVE_FIRST]] · **record check:** [[PRE_RECORD_CHECKLIST]] · **system pin:** [[../../00-Index/README|Games/WoW/00-Index]]

## Ramble to story — under two minutes

1. **0:00–0:20 — Heart:** finish: “The real reason I want to talk about this is…”
2. **0:20–0:45 — Example:** name one moment you actually saw, felt, tried, forgot, or laughed at.
3. **0:45–1:15 — Three beats:** write only the beginning, turn, and landing. Add two more beats only if needed.
4. **1:15–1:40 — Hook last:** pull one honest phrase from the heart or example; do not manufacture drama.
5. **1:40–2:00 — Fence facts:** mark anything uncertain, pick a simple B-roll vibe, and record. You can tighten afterward.

If the clean version stops sounding like you, keep the ramble and use the tighter version only as a map.
