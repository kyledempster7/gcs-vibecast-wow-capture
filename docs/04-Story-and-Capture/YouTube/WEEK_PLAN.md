# WEEK PLAN — Explorer series (talk + game B-roll)

**Format locked lean:**
- **Talking video** over background **player** gameplay (YouTube)
- Same audio can ship as **podcast** (Substack audio)
- Runtime: **10–15 min** per episode (default ~10–12)
- Mic: **Kyle solo** · Mac/Macraven = background friend only → [[NO_GUESTS]]

**Tour:** [[WORKBOOK]] · **Board:** [[WOTLK_Veteran_Midnight_Return_Series|series hub]] · [[BATCH_RECORD_BOARD]]

---

## What “a week’s worth” means

| Pillar | Target | Notes |
|--------|--------|--------|
| **Episodes** | **3–7** takes in a week if grinding the arc · **or** 2–3 if casual | 7 packs already on disk (EP01–07) |
| **Per take** | 10–15 min yap | Cold open → middle → soft CTA |
| **B-roll under talk** | Prefer **travel / flying mounts** while talking | Explorer-series thread · visually stimulating · low overlay risk |
| **Extra pure B-roll** | Optional separate clips | FOOTAGE_WISHLIST · no chat if possible |
| **Publish** | YT video + Substack podcast (same master OK) | Post can wait; record first |

**Honest default week (first ship week):**

| Day feel | Do |
|----------|-----|
| **Night A** | EP01 + EP03 (identity + friendship) · travel B-roll under |
| **Night B** | EP02 (gap years from LORE) + EP04 (systems) |
| **Night C** | EP05 + EP06 + EP07 (or split across next week) |
| **Anytime** | 10–20 min pure travel capture for the bank |

You do **not** need seven polished publishes in seven days — you need **audio masters** + **enough B-roll**. Chop later.
