# Player B-roll notes — under the talk

**Doctrine:** Messy/presentable **player content** is fine. Not cinematic perfection.  
**Series thread:** **Explorer** — travel / flying mounts while talking is a first-class method.  
**Reuse:** Same footage can sit under multiple EPs.  
**Mac:** silent progress / duo gameplay / **pictures of her progress** only — never force VO.

**Week plan:** [[WEEK_PLAN]] · **Wishlist:** [[../../community-surface/FOOTAGE_WISHLIST|FOOTAGE_WISHLIST]] · **Bridge:** [[../../community-surface/EPISODE_BRIDGE|EPISODE_BRIDGE]]

---

## Preferred while yapping (locked lean)

| Priority | What | Why |
|----------|------|-----|
| **#1** | **Travel / flying mounts / long routes** | Stimulating · explorer feel · often cleaner UI · easy to leave running while you talk |
| **#2** | Questing with **quest log cleaned** | Story motion |
| **#3** | Pure B-roll bank (no talk) | Extra cuts · no chat if possible |

**Talk-while-flying recipe:** open pack → start a scenic flight path → mic on → yap 10–15 min → land when done.

---

## Chat / private conversations

You already have days of questing footage with **private chat** in frame. That’s usable **if** post can:

| Option | When |
|--------|------|
| **Blur chat panel** in FCPX / editor | Best for “had to capture with chat open” |
| **Crop** so chat is off-frame | Fast when layout allows |
| **Re-capture clean travel** for that segment | Best quality when you have time |
| **Audio-only master** + separate clean B-roll | Always safe |

**While recording new talk passes:** close chat if you can. If friends are online, prefer travel with chat hidden or plan blur.

Related tooling (if present): private `fcpx-broll-gaming` repo on GitHub — not required to record.
