# Positive friction — phrase bank (returner VO)

**Umbrella:** [[../../00-Index/WOW_CONTENT_UMBRELLA|WOW_CONTENT_UMBRELLA]]  
**Use on:** EP VO · IG · Class-P letters · soft dev feedback  
**Never:** channel-vs-Blizzard · guest call-ins · invented patch claims · ragebait

---

## The five-step loop (always)

1. **Name the struggle** — “friction for a returner…”  
2. **Show fighting it** — what you’re doing in this login  
3. **Invite peers** — “got this too? got a workaround?”  
4. **Soft letter** — one sentence of feedback energy for devs  
5. **Curiosity close** — next login / next EP

---

## Ready lines (pick, don’t stack)

### Name it
- “This is friction for a returner — not a skill issue, a *home feels different* issue.”
- “The client didn’t ask if I still know the map. It assumes I do.”
- “I’m not lost because I’m bad. I’m lost because the room rearranged while I was gone.”

### Show the fight
- “I’m working around it by slowing down and one system at a time.”
- “Tonight’s win is a clean session ritual — not ‘caught up.’”
- “I’m letting the character be undergeared and still fun.”

### Invite peers
- “Got this too? Drop one workaround that helped you return.”
- “If you came back from Wrath-brain years, what was the first UI that punched you?”
- “No homework assignment — just curious what worked for you.”

### Soft letter (one sentence)
- “If I were writing the devs, I’d ask for a clearer welcome-back path without spoiling discovery.”
- “Soft note: returners need orientation, not a guilt trip.”
- “I’d love systems that explain themselves once, then get out of the way.”

### Curiosity close
- “Next login I’ll try…”
- “Next episode we park the deep cuts and keep the feelings.”
- “Stopping while it’s still fun — that’s the product.”
