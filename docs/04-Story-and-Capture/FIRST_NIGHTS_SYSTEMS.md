## Systems that feel alien (bullet list)

Vault-backed only. Each line is a **feeling hook**, not a patch note.

### Account layer
- **Warband bank** — mats, overflow, sellables, weird old goods stage **off** the active toon (policy: unbound + stackable + not needed tonight → warband first).
- **Shared gold / staging** — economy readouts treat warband bank gold + mat routing as real account state (local-confirmed when capture is fresh).
- **Multi-toon heart board** — Pain / Agony / Havoc / Rot / Faith (and Mac’s seats) share one client era; Wrath brain still thinks “one main = one bags reality.”

### Looks vs power
- **Collections / transmog** — appearance is a long game; vault rule = **targets in notes**, giant appearance dumps stay in-game (addons optional).
- **Curated fantasy lists** — DK / WL class sets, Spooky wantlists, light SL wantlist — not “I own everything I see.”

### Story pathing
- **Chromie time / expansion pick** — Embassy Chromie (or Adventure Guide → Suggested) to open **one** chapter (vault default play: **Shadowlands** for Pain).
- **One chapter open** — SL beats / oneshot: ignore DF/TWW FOMO and alt Chromie swaps mid-session.
- **Yellow campaign only** — story default; renown shopping and dungeon spam are later nights.

### Power / UI feel
- **Scaling theater** — paper ilvl can look absurdly low while Legion-era kit still quests fine (onesheet language — do not invent current ilvl numbers on mic).
- **Modern UI density** — talent panels, Collections, Adventure Guide: name the **overwhelm**, not every button.
- **Addons as glasses** — recovery/audit notes exist; series audio stays about *feeling*, not CurseForge shopping.

### Playing with a friend
- **Duo menu, not forced meta** — stakeout pair IDs (Pets, Heals, tank school); levels move; say bands if stale.
- **Queue fail-closed on tank** — both DPS unless someone **states** Brew/Blood/Vengeance before queue.
- **Realm / CRZ honesty** — Kyle **Thrall** locked; Mac realm still **TODO** on CHARACTER_INDEX — do not claim “same server” until filled.

### Session ritual
- **Full logout ends the night** — character select / exit; capture may auto when healthy; **no agent pings**.
- **Quit while fun** — hard stop culture from duo card (no “one more dungeon” guilt).
