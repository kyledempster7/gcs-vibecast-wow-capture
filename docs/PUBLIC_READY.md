## One sentence

VibeCast is a dual-machine **capture → human taste → package** program for World of Warcraft B-roll and social-ready media that **never invents footage** and **never auto-publishes**.

## Loop

```
Windows play + OBS dual audio
        ↓ Session-End-Ship
candidates + markers on D:
        ↓ Mac soft_poll / harvest (only when ready_today)
review-pack
        ↓ human KEEP / REJECT
Moments archive + local product package (product_ready)
        ↓ explicit kyle_go only
optional social (Zernio / fleet) — else stay NOT_ARMED
```

## Laws

1. **No invent FOOTAGE** — empty days stay empty; markers-only ≠ masters  
2. **Human KEEP** — agents score and shortlist; Kyle decides  
3. **No silent publish** — ARM default deny; no “ship because package exists”  
4. **Today honesty** — `ready_any` for prior days never pretends to be `ready_today`
